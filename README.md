# 🍩 Nyan Bull Terrier (Kiara Edition) 🐾✨

Un homenaje interactivo y retro arcade al legendario meme de **Nyan Cat**, protagonizado por una hermosa Bull Terrier café con blanco que viaja por el cosmos con cuerpo de dona glaseada de chocolate y chispas de arcoíris.

---

## 💖 La Historia Detrás del Proyecto

> *"Este proyecto nació una tarde en la que estaba aburrida y quise ponerme a experimentar con código, animaciones y React. Pero sobre todo, lo hice inspirada por el inmenso amor que le tengo a mi perrita **Kiara**, una Bull Terrier café con blanco que alegra todos mis días."*  
> — **Juli**

---

## 🚀 Características

* **Sprite Animado Personalizado:**
  * Cabeza con el perfil convexo (egg-shaped) y orejas puntiagudas distintivas de Bull Terrier.
  * Parche café en el ojo derecho y cuerpo blanco/marrón.
  * Cuerpo de dona glaseada horneada con chispas de colores.
  * Patitas trotando en ciclo continuo y cola oscilante.
* **Efectos Cósmicos Retro:**
  * Estela de arcoíris ondulante continua de 6 colores generada con Canvas.
  * Campo de estrellas pixel art en capas con efecto paralaje.
  * Filtro sutil de líneas de escaneo estilo pantalla CRT arcade.
* **Música 8-Bit Chiptune Nativa:**
  * Sintetizador retro generado completamente en tiempo real con la **Web Audio API** (sin librerías pesadas ni archivos MP3 externos).
* **Modo HYPERDRIVE:**
  * Botón interactivo para triplicar la velocidad del viaje espacial, el ritmo del arcoíris y el tempo de la música.
* **Contador de Distancia:**
  * Marcador de kilómetros recorridos en tiempo real en la barra de control HUD.

* **React 18**
* **Vite**

* **Web Audio API** (Sintetizador 8-bit)

## 💻 Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone git@github.com:JFlorezQ/nyan-kiara.git
   cd nyan-kiara
   ```

2. **Instalar dependencias:**
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo:**
   ```bash
   npm run dev
   ```

4. Abre en tu navegador la URL indicada (usualmente `http://localhost:3000`).
